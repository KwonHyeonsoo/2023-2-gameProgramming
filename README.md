# 🌀 Slime Escape

슬라임의 추격을 피해 달려라!  
플랫폼 위를 달리며 선택과 생존이 갈리는 3D 플랫포머 러닝 게임

---

## 🎮 장르

- **3D 플랫폼 러닝 게임 (3D Platform Running Game)**  
- **플레이 시점**: Back View (후면 시점)

---

## 📖 게임 스토리

슬라임 무리의 끈질긴 추격이 시작된다!  
끊임없이 생성되는 플랫폼을 뛰어넘으며 슬라임의 손아귀에서 벗어나 높은 점수를 노려보세요.

---

## 🕹️ 조작법

| 키 입력 | 동작 설명 |
|--------|------------|
| `W`, `A`, `S`, `D` | 캐릭터 이동 |
| `Space` | 점프 |

---

## 🧩 게임 흐름 및 시스템

1. **Start 버튼 클릭 시 게임 시작**  
   - 플랫폼, 캐릭터, 슬라임이 생성됨

2. **슬라임 추격**  
   - 슬라임이 캐릭터를 추격  
   - 슬라임이 캐릭터에 닿으면 HP가 감소

3. **플랫폼 분기 선택**  
   - 2개의 플랫폼이 생성됨  
   - 플레이어는 점프로 (1)번 또는 (2)번 플랫폼을 선택 가능

4. **무작위 요소 등장**  
   - 선택한 플랫폼에는 랜덤하게 HP 포션 또는 슬라임 등장  
   - 전략적인 판단 필요

5. **추격자 따돌리기**  
   - 플랫폼을 넘을 때 슬라임이 떨어질 수 있어 추격을 일시적으로 중단시킬 수 있음

6. **게임 종료 조건**  
   - HP가 0이 되면 캐릭터 사망  
   - 게임은 시작 화면으로 돌아감
